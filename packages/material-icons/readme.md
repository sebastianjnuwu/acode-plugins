<p>The <strong>"Material Icons"</strong> is a plugin for <i>acode</i> that allows you to add icons that don't exist in the app and change the existing ones!</p>

-   New icons for files and folders
-   Acode more minimalist and beautiful
-   Easy and quick to use

</div>

<strong style="color: C329FF">• How to activate:</strong>

1. Requires an Acode build with the `fileIcons` API (versionCode **1012** or newer).
2. In Acode, open **Plugins**, search for **Material Icons** and download it.
3. Go to **Settings → App settings → Icon pack** and select **Material Icons**.
